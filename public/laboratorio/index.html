Condicionais em 1 Segundo: Booleano Puro
O if é um bifurcador: avalia uma condição booleana. True = executa o bloco; False = pula tudo e ignora.
Exemplo prático
Java / TypeScript 
if (usuario.isPremium()) {
    liberarAcessoTotal(); // Executa se for TRUE
}
Se isPremium = false, o que o compilador faz com essa linha?
